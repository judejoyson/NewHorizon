# New Horizon Group Homes — Website

Promotional website for **New Horizon Group Homes**, APD-licensed group homes in
Seffner, Florida providing residential care for adults with disabilities.

**Live site:** https://judejoyson.github.io/NewHorizon/

## What's inside

- `index.html` — single-page site built with semantic HTML (hero, about, services, homes, gallery, contact)
- `styles.css` — custom responsive CSS (no frameworks)
- `sitemap.xml` / `robots.txt` — search engine crawl support
- `Joseph care group home images/`, `Mary care group home/`, `Smokey mountain group home/` — property photos for the three homes

## SEO features

- Descriptive `<title>`, meta description, and keyword tags targeting local search
  (e.g., "group home Seffner FL", "APD licensed group home Florida")
- JSON-LD `LocalBusiness` structured data for both homes (address, phone, license)
- Open Graph and Twitter Card tags for social sharing
- Semantic headings, descriptive image `alt` text, and `geo.*` local-search meta tags
- `sitemap.xml` and `robots.txt` for crawler indexing

## Deployment

Hosted on **GitHub Pages** from the `main` branch root. Pushing to `main`
automatically redeploys the site.
